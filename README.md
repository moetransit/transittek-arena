# transitTek Arena

A rhythm-movement arena shooter written in Rust with Bevy. Every hop and every shot is graded against the song's beat grid.

Trailer and info: https://moetransitauthority.com/arena/

This repository only hosts the release builds. Get the zip for your system from [Releases](../../releases).

Unzip it, keep the `assets` folder next to the game, and run `mta-arcade`. The builds are unsigned:
- **Windows** (64-bit): if SmartScreen stops it, click More info, then Run anyway.
- **macOS** (Apple Silicon): double-click `mta-arcade`. When macOS blocks it, open System Settings → Privacy & Security and click Open Anyway. Or, in Terminal: `xattr -dr com.apple.quarantine` on the unzipped folder.
- **Linux** (x86-64, glibc 2.39+, e.g. Ubuntu 24.04): run `./mta-arcade` from a terminal in the folder.

Free, non-commercial showcase build. All 31 songs are by moe transit authority; some maps and textures are community work by their original authors.
